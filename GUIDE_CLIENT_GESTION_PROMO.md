# 🎯 GUIDE CLIENT : Gérer les Promotions

## 👋 Bonjour !

Ce guide vous explique comment **changer facilement le nom de vos promotions** sur votre site (PROMO MAGAL → PROMO TABASKI, etc.).

**Pas besoin de connaissances techniques !** Tout se fait depuis votre interface d'administration.

---

## 🚀 Accéder à la Gestion des Promos

### Étape 1 : Connexion à l'Administration
1. Allez sur votre site : `https://www.maguitaskin.com`
2. Ajoutez `/admin/login` à la fin : `https://www.maguitaskin.com/admin/login`
3. Entrez vos identifiants :
   - **Email** : votre_email@example.com
   - **Mot de passe** : ••••••••
4. Cliquez sur **Connexion**

### Étape 2 : Ouvrir les Paramètres
1. Dans le menu à gauche, cliquez sur **⚙️ Paramètres**
2. Vous arrivez sur la page de configuration

---

## ✏️ Changer le Nom de la Promo

Vous verrez 3 champs à remplir :

### 1️⃣ Nom Court
**Exemple :** `PROMO MAGAL`

📍 **Où ça apparaît ?**  
Sur les petits badges rouges sur les produits

💡 **Conseils :**
- Gardez-le court (2-3 mots maximum)
- Utilisez des MAJUSCULES
- Exemples :
  - `PROMO MAGAL`
  - `PROMO TABASKI`
  - `PROMO RAMADAN`
  - `SOLDES D'ÉTÉ`
  - `BLACK FRIDAY`

---

### 2️⃣ Nom Complet
**Exemple :** `MEGA PROMO MAGAL`

📍 **Où ça apparaît ?**  
Dans la grande bannière colorée en haut de votre page d'accueil

💡 **Conseils :**
- Peut être plus long et descriptif
- Ajoutez "MEGA", "SUPER", "GRANDE", etc. pour plus d'impact
- Exemples :
  - `MEGA PROMO MAGAL`
  - `GRANDE PROMO TABASKI`
  - `SUPER SOLDES D'ÉTÉ`
  - `PROMO EXCEPTIONNELLE RAMADAN`

---

### 3️⃣ Emoji (optionnel)
**Exemple :** `🔥`

📍 **Où ça apparaît ?**  
Juste avant le texte de la promo (partout)

💡 **Suggestions d'emojis :**

Vous verrez des boutons avec des suggestions. Cliquez simplement dessus !

## 💾 Enregistrer vos Changements

1. Vérifiez que tout est correct dans l'aperçu
2. Cliquez sur le bouton **💾 Enregistrer** (grand bouton violet)
3. Attendez 2 secondes
4. Vous verrez un message : **"✅ Paramètres enregistrés !"**
5. C'est tout ! Votre site est mis à jour instantanément

## 🔄 Workflow Recommandé

### Pour changer la promo (5 minutes) :

1. **Connexion** → `/admin/login`
2. **Paramètres** → Cliquez sur "⚙️ Paramètres" dans le menu
3. **Choisir un exemple** → Cliquez sur un exemple (ex: PROMO TABASKI)
4. **Personnaliser** → Modifiez si besoin (optionnel)
5. **Vérifier aperçu** → Regardez l'aperçu en bas
6. **Enregistrer** → Cliquez sur le bouton violet
7. **Vérifier site** → Allez sur la page d'accueil pour voir le résultat

## ❓ Questions Fréquentes (FAQ)

### Q : Les changements sont-ils instantanés ?
**R :** Oui ! Dès que vous cliquez sur "Enregistrer", votre site est mis à jour en 1-2 secondes.

### Q : Puis-je revenir en arrière ?
**R :** Oui ! Vous pouvez retourner dans Paramètres et changer à nouveau. Il n'y a pas de limite.

### Q : Est-ce que je peux laisser le champ emoji vide ?
**R :** Oui, c'est optionnel. Mais un emoji attire plus l'attention des clients !

### Q : Dois-je changer autre chose après avoir changé le nom de la promo ?
**R :** Non ! Le nom change automatiquement partout sur le site (bannière, badges, pages produits).

### Q : Que faire si je fais une erreur ?
**R :** Pas de panique ! Retournez dans Paramètres et corrigez. Vous pouvez modifier autant de fois que vous voulez.

### Q : Est-ce que ça affecte mes prix ?
**R :** Non ! Le nom de la promo et les prix sont séparés. Pour changer les prix, allez dans "Gammes".
